# Mobile screenshot set

Captured on 2026-07-07 from the local Next dev server.

Representative phone sizes:

- `small-android-360x800`: narrower Android phones and compact mobile layouts.
- `typical-iphone-390x844`: common modern iPhone-sized viewport; full-page captures are included for every main route.
- `large-android-412x915`: common Pixel/Samsung-sized viewport.
- `large-iphone-430x932`: large iPhone / Pro Max-sized viewport.

Main comparison folder:

- `representative/`: first-screen captures for each route at all four sizes, plus full-page captures at `typical-iphone-390x844`.

Compatibility captures:

- Root-level `*-393-fold.png` and `*-393-full.png` files capture each main route at a 393px mobile viewport.
- `home-360-*` and `home-393-*` also refresh the legacy `screenshots/current/m360-*` and `screenshots/current/m393-*` files.
